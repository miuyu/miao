# CMYK MatchColors - 專業印刷色階調色盤與五色配色系統

CMYK MatchColors 是一套專為平面設計師、印刷工藝師與數位創作者打造的現代化網頁色彩工具。**純原生 HTML5、CSS 與 JavaScript 構建，完全不需要安裝 Python 或 Node.js**，只要使用任何現代瀏覽器點開 `index.html` 即可立即離線運行！

---

## 🌟 核心功能特色

### 1. CMYK 與 RGB 雙模式自由切換調節（HEX 即時全聯動）
- **一鍵切換調色模式**：
  - **CMYK 印刷模式**：提供 C (青)、M (洋紅)、Y (黃)、K (黑) 四通道獨立漸層滑桿與 0% 至 100% 數字微調框，並即時監控總墨量 (Total Ink Coverage - TIC)。
  - **RGB 螢幕模式**：提供 R (紅)、G (綠)、B (藍) 三通道獨立專屬滑桿與 0 至 255 數字精確輸入框，並即時計算感知明度 (Relative Luminance)。
- **HEX 全域雙向無縫連動**：不論在 CMYK 或 RGB 模式下，修改滑桿立即推算 HEX 與互換數值；直接輸入 6 碼或 3 碼 HEX 代碼時，CMYK 與 RGB 滑桿及數字自動同步精準定位。
- **防止抖動與循環鎖**：內建防迴圈同步引擎，輸入數值流暢無延遲。
- **總墨量 TIC 警示與感知亮度儀表**：CMYK 模式顯示總墨量安全性提示（防止背印黏頁）；RGB 模式顯示螢幕輝度階層。

### 2. 全色階色彩選擇器（HTML5 Canvas 2D 高效能光譜）
- **雙層高解析度畫布架構**：採用底層光譜 + 頂層準心指針獨立圖層設計，滑鼠拖曳拾色無任何卡頓。
- **支援 Retina / HiDPI 螢幕縮放**：自動適應裝置像素比（Device Pixel Ratio），線條與指針維持極致清晰。
- **全色相與明暗度涵蓋**：
  - **全頻光譜模式**：水平方向涵蓋 0° ~ 360° 連續彩虹色階，垂直方向涵蓋白階至黑階的完整明暗階梯。
  - **飽和/明度模式**：專業級 HSV 2D 色彩矩陣，搭配色相 (Hue) 滑桿與明度 (Lightness) 滑桿進行精細調色。
- **經典印刷基準色票盤**：內建 16 組印刷常用的代表性色票（純 C/M/Y/K、富麗黑、海軍藍、珊瑚紅等），點擊一鍵快速載入。

### 3. 智慧五色和諧配色系統 (5-Color Harmonies)
- **五大色彩學調和模式切換**：
  1. **專業品牌五色 (Designer)**：主品牌色、次要輔色、強烈焦點色、紙張底色、印刷標題深色。
  2. **類似相鄰色 (Analogous)**：色相差 20° ~ 40° 的和諧相鄰五色。
  3. **互補分裂色 (Complementary)**：主色、180° 對比互補色、分裂互補色與柔和底色。
  4. **單色印刷色階 (Monochromatic)**：主色在 5 個不同明度與墨量階梯下的單色系深淺套色。
  5. **三等角和諧 (Triadic)**：視覺衝擊力強的 120° 三等角均勻分佈配色。
- **詳細色值與快捷操作**：
  - 每個色塊清楚標示角色定位、HEX 代碼與印刷 CMYK 數值。
  - 點擊「設為主色」立即將該色彩作為調色盤基底。
  - 獨立一鍵複製按鈕。
- **實體印刷視覺模擬器 (Print Mockup Preview)**：
  - 即時將當前五色配色套用至名片排版與海報設計中，直接預覽實體印刷搭配視覺效果。
